   1. What is Exception?
       An exception is an unwanted or unexpected event that occurs during the execution of a program and disrupts
       the normal flow of the program. 
   
   2. WHAT IS EXCEPTION HANDLING? 
      Exception Handling is a mechanism in Java that handles runtime errors so that the normal 
      flow of the program can continue without terminating unexpectedly. 
   
   3. WHY DO WE NEED EXCEPTION HANDLING?
      Without Exception Handling:
      ✔ Program terminates immediately.
      ✔ Remaining statements are not executed.
      ✔ Poor user experience.
      With Exception Handling:
      ✔ Prevents abnormal program termination.
      ✔ Maintains normal program flow.
      ✔ Makes programs more reliable.
      ✔ Helps identify and handle errors properly. 
   
   4. ADVANTAGES OF EXCEPTION HANDLING
      ✔ Prevents abnormal program termination.
      ✔ Maintains normal program flow.
      ✔ Improves program reliability.
      ✔ Makes debugging easier.
      ✔ Separates error-handling code from normal code.
      ✔ Improves code readability.

2. EXCEPTION HIERARCHY
   It is the classification of all errors and exceptions in Java. 
   All exceptions and errors are derived from the Throwable class. 
   Java uses this hierarchy to identify, classify, and handle different types of runtime problems.
